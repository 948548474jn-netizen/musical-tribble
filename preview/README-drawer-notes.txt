江南的设计抽屉 · 整抽屉热区与便签说明预览

解压后用 Chrome / Edge 打开「打开预览.html」。浏览器标签显示「整抽屉热区与便签说明预览」。

本版：
- 首页点击下层抽屉任意可见部分，包括前板、内壁、底板和内部文件，都可打开抽屉进入俯视。
- 打开后，内部文件仍分别进入作品集、简历和技能功能；空白返回与日夜开关保留。
- 粉色便签悬浮说明：打开档案 / 整个抽屉可点击。
- 橙色便签悬浮说明：留言 / 聊聊设计与合作。
- 标签背景为 30% 不透明填充，文字保持 100% 不透明，并使用毛玻璃底衬。
- 标签跟随便签位置，俯视状态下隐藏；首页可直接点击标签打开档案或留言。
- 滑动与拖动不触发抽屉打开，页面背景也不作为打开热区。

两份作品图片、主模型、字体、封面与简历已内嵌，保留车载HTML、快速活动全案的完整长图。
这是独立交互预览，没有发布网站。
