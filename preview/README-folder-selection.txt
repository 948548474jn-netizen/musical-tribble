江南的设计抽屉 · 文件选择动效版

解压后用 Chrome / Edge 打开「打开预览.html」。标签显示「文件选择动效版预览」。

操作：
1. 打开设计抽屉，进入俯视视角。
2. 悬停或点击个人简介、作品集、技能卡。文件会抬起、摆正并放大，其他文件略微让开，右侧显示蓝色说明卡。
3. 点击「查看档案」进入详细内容。点击弹窗外返回选中文件。
4. 点击红色按钮或桌面空白放回文件；再点击一次空白返回首页。
5. 可以直接选择另一份文件；上一份平滑归位。
6. 点击台灯或灯光按钮，继续切换白天/暗夜模式。

手机上点击文件进行选择，说明卡位于底部。系统减少动态效果时直接切换。
模型、字体和简历已内嵌。部分项目示意图需要联网。
这是独立交互预览文件，没有发布网站。
