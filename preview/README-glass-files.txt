江南的设计抽屉 · 毛玻璃折页档案预览

解压后用 Chrome / Edge 打开「打开预览.html」。标签显示「毛玻璃折页档案预览」。

本版：
- 移除右侧蓝色提示卡，全部操作合并到文件上的半透明毛玻璃标签。
- 标签自动避让；被选中文件挡住的其他文件，不再把标签压在选中文件正文上。
- 悬停/点击标签选择文件；选中后点击同一标签查看档案，标签右侧小按钮放回。
- 作品集为米色横向折页，浅紫细框、花体与像素混合标题、文件夹图案。
- 简历使用提供的原图，详情页和 PDF 下载均保留原图排版。可打开完整原图查看。
- 三维纸张有轻微折痕，原始简历图片和下载文件不添加折痕。
- 保留日夜切换、文件选择动效和空白逐层返回。

模型、封面、简历与字体均内嵌。部分作品示意图需联网。
这是独立交互预览，没有发布网站。
