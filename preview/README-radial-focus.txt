江南的设计抽屉 · 居中放射作品集交互预览

解压后用 Chrome / Edge 打开「打开预览.html」。标签显示「居中放射作品集交互预览」。

本版操作：
1. 打开抽屉。桌面中的文件与悬浮标签均已缩小，改为点击触发。
2. 点击作品集、个人简介（简历）或技能卡：主体按静置尺寸放大 20%，移动到画面中央，背景变成毛玻璃虚化。小屏幕按可用空间限制尺寸。
3. 再点击作品集封面：作品集下移，六张带厚度的圆角卡片从主体展开、放射排列。
   车载HTML / IP联名KV设计 / 快速活动全案设计 / IP设计 / AIGC动效设计 / UI设计。
   六类目前都是作品待添加的预留位置，没有填入虚构的设计项目。
4. 简历：按住拖动，旋转观察角度；点击「回正」恢复。方向键也可以调整，Home 键回正。「查看原图」可阅读完整简历。
5. 再点击技能卡：展开四组平行技能卡。手机上按两列平行排列，保证完整显示。
6. 再次点击作品集/技能主体可收起子卡片。点击旁边空白、右上角退出或 Escape，直接退出功能并返回俯视抽屉。
7. 台灯日夜切换继续保留。系统减少动态效果时直接切换。

主场景、封面、简历、字体已内嵌。旧页面部分项目示意图需联网；新增六类作品全部为本地占位卡。
这是独立交互预览，没有发布网站。
